# IBM Displaywriter Beam Spring Keyboard Restoration

![Restored DisplayWriter](report/images/finished_2.jpg)

A detailed account of restoring an original IBM Displaywriter beam spring keyboard, including disassembly, switch repair, cleaning, reassembly, controller construction, firmware, and the finished result.

The project involved repairing damaged original switches, designing custom 3D-printed restoration tools, fabricating replacement components, and converting the keyboard for use with a modern computer.

**[Read the full restoration report](report/index.md)**

The report includes photographs, detailed technical explanations, practical advice, and links to custom 3D-printed fixtures.
